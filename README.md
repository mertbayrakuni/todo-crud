# Todo CRUD (React + Vite + Tailwind)

A simple Todo application built with React.  
Includes full CRUD operations and localStorage persistence.

## Features
- ✅ Add todo
- ✅ List todos
- ✅ Update todo (Edit / Save / Cancel)
- ✅ Delete todo
- ✅ Mark as done (checkbox)
- ✅ Validation (1–25 characters)
- ✅ Live character counter
- ✅ Saved in localStorage (data stays after refresh)
