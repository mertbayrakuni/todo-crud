# Todo CRUD

A simple Todo application built with **React + Vite + Tailwind CSS**.

## 🚀 Features

- ✅ Add todo
- ✅ List todos
- ✅ Edit / Save / Cancel
- ✅ Delete todo
- ✅ Mark as done
- ✅ Validation (1–25 characters)
- ✅ Character counter
- ✅ localStorage persistence

## 🛠 Tech Stack

- React (Vite)
- Tailwind CSS

## 📦 Run Locally

```bash
npm install
npm run dev
